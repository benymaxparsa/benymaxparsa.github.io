# Redesign v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v3 "graph-paper notebook" look with the v4 warm-cream / single-blue / pill-and-rounded-card system, with a 5-group navigation and a bento homepage, without changing any URL or content.

**Architecture:** New token-driven stylesheets under `src/styles/v4/` replace `site.css` and `additions.css` outright (no layering). Markup changes stay inside the existing Astro components and layouts; nav becomes grouped data in `src/i18n.ts`. Behaviour stays in `src/scripts/enhancements.ts` (menu/dropdowns, reveal) and `src/scripts/graph.ts` (palette only).

**Order note:** do Task 6 Steps 1–4 (`firstImage`) before Task 4, which uses it.

**Tech Stack:** Astro 7 static build, plain CSS custom properties, TypeScript, Pagefind, puppeteer-core checks in `scripts/`, `node --test` (Node 25, runs `.ts` directly).

**Spec:** `docs/superpowers/specs/2026-11-08-redesign-v4-design.md`

## Global Constraints

- Work in the worktree `../benymaxparsa-redesign` on branch `feat/redesign-v4`; never touch `master` or PR #9.
- No URL changes: `diff /tmp/v4-master-urls.txt <(cd dist && find . -name '*.html' | sort)` must print nothing (baseline made in Task 1 Step 0).
- EN/FR parity: every new UI string lives in `ui.en` and `ui.fr` in `src/i18n.ts`; FR homepage `src/pages/fr/index.astro` mirrors EN.
- Only new dependency: `@fontsource-variable/inter`. Remove `@fontsource-variable/schibsted-grotesk` and `@fontsource-variable/source-serif-4`.
- Colours only through tokens (`--canvas`, `--surface`, `--surface-pill`, `--ink`, `--muted`, `--hairline`, `--accent`, `--accent-press`); values exactly as the spec's two colour tables. Footer is `#141413` in both modes.
- Radii: 8 / 16 / 24 / 32 / 999px only. Shadows: only the nav-pill shadow and the card hover shadow from the spec.
- Every motion rule sits inside `@media (prefers-reduced-motion: no-preference)`; content is visible without JS.
- WCAG AA contrast, visible focus ring (`2px solid var(--accent)`, offset 2px) on every interactive element, 44px min touch targets.
- Ponytail: smallest complete change, no speculative options, delete what the new design no longer uses.
- Commits: Conventional Commits, no AI trailers. GitHub issues are disabled on this repo, so commits carry no issue number; the PR description holds the scope.

## Review Focus

1. **French strings that overflow the nav pill** (e.g. "Enseignement", "À propos") at 1024px — the pill must not wrap or scroll horizontally. Test in Task 2.
2. **Theme set to dark by the toggle while the OS is light** (and vice versa) — every token, the graph palette and the footer must follow `data-theme`, not only the media query. Test in Task 1 and Task 4.
3. **Keyboard user opening a nav dropdown then tabbing past it** — the panel closes, focus is never trapped, Esc returns focus to its button. Test in Task 2.
4. **Project with an image path that the optimiser rewrote to `<picture>` / WebP** — the card helper must still find the first image in the markdown source. Test in Task 6.
5. **Reduced-motion visitor or JS failure** — no element stays at opacity 0. Test in Task 5.
