- Conception et développement en Swift d’une application de barre des menus macOS qui dispose les fenêtres par gestes à deux doigts sur leur barre de titre : balayer pour les moitiés, tiers et quarts, vers le haut pour remplir l’écran, vers le bas pour restaurer ou réduire, pincer pour le plein écran ou la fermeture.
- Deux doigts posés un instant sur une barre de titre font apparaître une grille de dispositions : il suffit de glisser puis de lever les doigts pour placer la fenêtre dans la case choisie ; ⌘ et un balayage envoient la fenêtre sur un autre écran.
- Gestes aussi sur les icônes du Dock : afficher toutes les fenêtres d’une application, passer à sa fenêtre suivante, la masquer ou la quitter, et ramener une fenêtre réduite directement dans une disposition.
- Un aperçu montre où la fenêtre se placera et un retour haptique confirme le geste, exécuté quand les doigts se lèvent ; Échap annule, et le défilement et le zoom ordinaires passent sans changement.
- Chaque geste est reconfigurable, avec raccourcis clavier facultatifs, espacement entre les fenêtres, exclusions par application et ouverture à la connexion ; signée avec un Developer ID, notariée par Apple et installable avec Homebrew, sous macOS 14 Sonoma ou plus récent.
